MY SPACE - GitHub Pages 사용 방법

1. ZIP 파일의 압축을 풉니다.
2. index.html, paper-scene.png, holo-scene.png 파일을 GitHub 저장소 최상단에 올립니다.
3. GitHub 저장소의 Settings > Pages로 이동합니다.
4. Deploy from a branch / main / (root)를 선택하고 저장합니다.

사용 방법
- 오른쪽 위의 '화면 꾸미기'를 누릅니다.
- 편집할 위젯을 누른 뒤 손가락으로 위치를 옮길 수 있습니다.
- 투명도, 가로·세로 크기, 모서리, 글자 크기를 조절할 수 있습니다.
- 7개 테마를 선택할 수 있으며 각 테마의 위젯 배치는 따로 저장됩니다.
- 할 일, 일정, 음악 링크, 테마 및 위젯 설정은 현재 기기의 브라우저에 저장됩니다.
- 날씨 버튼은 브라우저에서 위치 접근을 허용해야 작동합니다.
- Apple Music은 앨범 또는 플레이리스트의 공유 링크를 입력하면 됩니다.

아이패드 Safari에서 공유 버튼 > 홈 화면에 추가를 선택하면 웹앱처럼 실행할 수 있습니다.
