# MY SPACE iPad Web App

## GitHub Pages에 올리기

1. 이 ZIP을 압축 해제합니다.
2. GitHub 저장소 `web`의 기존 파일을 모두 지우고, 압축을 푼 파일 전체를 저장소 최상위에 올립니다.
3. 반드시 `index.html`과 `theme-*-v2.png` 8개가 같은 폴더에 있어야 합니다.
4. GitHub의 **Settings → Pages**에서 **Deploy from a branch**, 브랜치 **main**, 폴더 **/(root)**를 선택하고 저장합니다.
5. 1~3분 뒤 `https://bms3170-jpg.github.io/web/`를 새로고침합니다.

이 앱은 iPad 가로 4:3 화면에 맞춰 자동 축소되며 페이지 스크롤과 더블 탭 확대를 막습니다. 할 일과 일정, 위젯 위치·크기·투명도 설정은 브라우저에 저장됩니다.
